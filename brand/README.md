# OpenParty brand

**The mark:** two friends side by side, one gold and one ivory: two different people, perfectly in step. The same shape reads as a pause button.

| File | Use |
|---|---|
| `logo-mark.svg` | App icon: the mark on its warm near-black tile. Source for `tools/make-icons.py`. |
| `logo-symbol-dark-bg.svg` | The two friends alone, for dark backgrounds (gold + ivory). |
| `logo-symbol-light-bg.svg` | The two friends alone, for light backgrounds (gold + ink). |
| `logo-lockup-dark-bg.png`, `logo-lockup-light-bg.png` | Symbol and wordmark, transparent background. |

## Colors

| Role | Dark | Light |
|---|---|---|
| Background | `#0E0D0B` (tile `#1D1913` → `#0F0D0A`) | `#F6F1E7` |
| Surface | `#17140F` | `#FFFDF9` |
| Text | `#F3EEE3` ivory | `#17140F` ink |
| Muted | `#9C9487` | `#6E675C` |
| Accent | `#E9A23B` popcorn gold (gradient `#F6C25A` → `#DC8F26`) | `#A86A12` for text and links; `#E9A23B` for buttons |

Text on gold is always ink `#17140F`, never white. Gold is the accent, so use it sparingly.

## Type

- **Wordmark:** Fraunces SemiBold (600), tracking −1.5%. The font is in `fonts/` under the SIL Open Font License (`fonts/Fraunces-OFL.txt`).
- **Interface:** the system font, as the extension uses today.
